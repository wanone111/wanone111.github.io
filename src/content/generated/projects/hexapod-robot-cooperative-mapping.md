## 项目背景与目标

在未知室内环境中，单机探索受限于通行能力与单一视角。本项目搭建了一套异构多机器人协同感知与建图系统，由高云 BX72 麦轮小车（具备自主导航、局部避障与视觉目标跟踪能力）与 ACG720 六足机器人（补充复杂区域观测）共同协作，将两台设备各自构建的局部激光地图统一到共同坐标系下，实现跨机地图共享。

## 系统架构与软硬件分工

系统采用底层实时控制与上层感知规划解耦的异构架构：

| 节点 / 平台 | 硬件载体 | 核心职责 |
| --- | --- | --- |
| BX72 麦轮小车底层 | 高云 FPGA | 采集激光雷达、IMU 与轮式编码器，执行轮速闭环控制与近障硬停车保护，经以太网与上位机通信 |
| BX72 上位机与控制台 | NVIDIA Jetson（ROS 2 Humble） | 运行激光建图、路径规划、航点调度、TensorRT + ByteTrack 视觉跟踪，以及统一的 Web 监控控制台 |
| ACG720 六足感知链 | 高云 FPGA + 树莓派 + Jetson | FPGA 采集 D500 雷达与相机原始帧，经树莓派桥接至 Jetson，由雷达 ICP 里程计与 SLAM Toolbox 输出独立地图 |
| 多机协同融合层 | 协同后端服务 | 基于共同标定板解算两机相对位姿变换，完成栅格地图融合、共享下发与任务视图汇总 |

## 核心技术实现

### 1. 基于共同标定板的跨机地图对齐

两台机器人各自维护独立的本地坐标系（`odom` / `map`），单纯统一话题命名无法自动对齐空间坐标。本系统利用共同视觉标定板（AprilTag）建立两机之间的空间坐标变换：

1. **相机内参与安装外参标定**：采集多视角无损原图拟合相机内参，结合现场量测与参照物雷达扫描确定相机光心相对激光雷达原点的平移与旋转外参（包括图像倒置带来的 180° 光轴旋转补偿）。
2. **时间对齐与位姿解算**：当两台机器人同时观测到同一块 AprilTag 标定板时，分别按各自图像采集时间戳查询对应的 `camera → map` 坐标变换（避免动态 TF 迟到导致错配），算出标定板在两张地图中的位姿，进而反推出两张地图之间的相对平移与旋转变换。
3. **共享栅格融合**：以参考地图为基准，将六足观测到的占据与空闲栅格投影至小车坐标系并下发共享地图，同时保留原始地图与融合视图的边界。关于历史地图与实时局部观测的融合规则，详见 [机器人地图与实时观测的融合](/notes/robotics/map-and-live-observations/)。

### 2. 边缘视觉检测与跟踪链路

小车侧集成 TensorRT 10 + ByteTrack 实时视觉链路，面向“跟随、接近、搜索并接近”三类任务：

- **接口契约与零拷贝优化**：严格校验推理引擎输入输出张量形状与数据类型，保证预处理缩放（letterbox）与框坐标还原成对一致；将图像输入由 `toCvCopy` 改为 `toCvShare`，在 640×360 `bgr8` 格式下每帧减少约 691 KB 像素拷贝。
- **观测新鲜度与 ID 隔离**：对外只发布本帧真实匹配的检测框，不把纯卡尔曼预测混作新观测；目标 ID 绑定会话编号，防止跟踪器重置后误认旧目标，并沿原始图像时间戳持续检查数据时效。

### 3. 硬件平台演进与前期原型

现役双机协同架构由两代前期原型迭代而来：
- **四足 FPGA 控制原型**：早期在高云 Tang Primer 25K 平台上验证了八路舵机 PWM 控制、无线指令接收与激光雷达独立 GPIO 数据采集，积累了 FPGA 舵机分层控制与串口吞吐经验。
- **RGB-D 六足原型**：初期尝试用深度相机完成视觉里程计、地面高度过滤与障碍扫描，并验证了人工输入相对位姿的栅格合并与 Nav2 隔离规划；随后针对近场盲区与算力开销问题，切换为现役的 ACG720 雷达建图 + 相机对齐方案。

## 验证情况与当前边界

- **已验证成果**：在实机现场完成两机共同标定板对齐，实测两张地图倾角差为 9.268°（满足 15° 校验门限），生成 296 × 274 格（分辨率 5 cm）的共享地图，双机均有栅格写入且小车端正常接收；小车侧已完成零速通信回执、隔离视觉任务与控制台去重精简。
- **当前局限与后续工作**：现阶段六足仍由操作员移动参与建图；后续将重点核对两机同向面对标定板时的雷达前向、机头朝向与控制台显示一致性，并进一步评估双机连续运动下的长期定位稳定性与自主协同探索能力。
